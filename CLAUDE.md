# Accountancy Boards Practice Hub — maintainer notes

## Architecture
- `index.html` is the whole app (one self-contained file). It is GENERATED by `python3 tools/build.py`. Never hand-edit it; edit the sources in `tools/` and rebuild.
- Home view lists subject sections (currently Management Services → CVP Analysis). Each section has tabs: Handout, Questions, Sales Mix.
- JS is minimal: view switching, tab state in localStorage (wrapped in try/catch), and Reveal/Hide answer toggles.

## Style rules (set by the user)
- Font: Arial only. Theme: light pink and white.
- Keep it simple: problem, question, choices, Reveal answer button. No timer, scoring or animations unless asked.
- Peso sign is ₱. Numbers use thousands separators.

## Questions (`tools/cvp_questions.py`)
- Each problem type is a function (q1…q13, q40) that takes the givens and COMPUTES the correct answer, distractors and solution steps. Never type an answer by hand.
- `part()` asserts the 4 options are distinct. Options are shuffled with a fixed seed so letters stay stable between builds.
- Givens are chosen so answers come out as whole numbers (DOL may have decimals).
- Solutions follow the handout's formulas (CM per unit/ratio, (FC + profit) ÷ CM, after-tax ÷ (1 − t), package method for sales mix, DOL = CM ÷ profit).
- Distractors model real mistakes: forgetting the tax gross-up, using the variable cost ratio, using a single product's ratio, etc.

## Handout (`tools/cvp_handout.html`)
- Written in our own words. Do NOT paste text or branding from review center handouts (they forbid distribution and this repo is public).

## Verification
After any change: run `python3 tools/build.py`, check the console count, and syntax-check the inline script (`node --check` on the extracted `<script>`). Check the page at 400px width for horizontal overflow.
